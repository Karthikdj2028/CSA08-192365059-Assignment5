# Task B3 – Loops vs pandas vs SQL

Install dependencies: `python -m pip install -r requirements.txt`

Run: `python Task08/compare_methods.py`

Generates hourly data for 1, 12 and 120 stations, compares Python/pandas/SQLite daily means, profiles the Python loop and saves timing_results.csv. The 120-station case creates about 1.05 million rows and may take several minutes.
